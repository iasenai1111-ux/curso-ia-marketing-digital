# IA aplicadas ao Marketing Digital: aulas interativas

Material do aluno do curso **IA aplicadas ao Marketing Digital**. Cada aula é uma página que abre direto no navegador, sem instalar nada.

**👉 Acesse: https://iasenai1111-ux.github.io/curso-ia-marketing-digital/**

## Aulas

| Nº | Aula | Conteúdo | Link |
|---|---|---|---|
| 01 | Fundamentos de IA + Prática | O que é IA e como ela entra no trabalho de marketing | 🔜 em breve |
| 02 | Fundamentos de Marketing Digital + Prática | 4Ps, evolução do Marketing 1.0 ao 7.0, mercado digital no Brasil, experiência mobile, indicadores, quiz e prática de análise de mercado com IA | [Abrir](https://iasenai1111-ux.github.io/curso-ia-marketing-digital/aula-02/) |

## Como usar

- Avance com os botões **Anterior** e **Próximo** ou com as setas do teclado.
- Use **Tela cheia** para apresentar ou para ler no celular.
- Cada aula termina com um quiz e uma prática para fazer em grupo.

## Estrutura do repositório

```
index.html          página inicial, com a lista de aulas
aula-02/index.html  Aula 2
```

Cada aula é um único arquivo HTML, sem bibliotecas externas. Para reaproveitar, basta copiar a pasta.

## Fontes

Os dados de mercado e as referências usados em cada aula estão listados no último slide da própria aula.
